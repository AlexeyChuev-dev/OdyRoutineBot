# OdyRoutineBot

Личный Telegram-бот для задач, напоминаний, клиентов, регулярных задач и делегирования задач другим людям. Работает алгоритмически, без AI.

## Новое: задачи другим людям

1. Человек, которому будут ставить задачи, должен один раз открыть бота и нажать `/start`.
2. Открой `👤 Люди` → `➕ Добавить человека`.
3. Введи его Telegram username, например `@artem`.
4. Задай короткий алиас, например `Артем`.
5. После этого можно писать быстрые команды:

```text
Таска Артему дай доступы
Задача Артем проверить кассу
Таска @artem проверить домен
```

Бот определит исполнителя по алиасу/username и дальше покажет обычные кнопки выбора даты, времени, клиента и напоминания.

Исполнитель получит задачу в боте. Постановщик увидит её в `📤 Я поставил`. Когда исполнитель нажмёт `✅ Выполнено`, постановщик получит уведомление.

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python3 bot.py
```

Существующая SQLite-база мигрируется автоматически: старые задачи остаются назначенными их владельцам.
