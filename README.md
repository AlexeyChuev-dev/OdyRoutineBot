# Routine Bot

Личный Telegram-бот для задач, напоминаний, клиентов и регулярных задач.
Работает алгоритмически, без AI.

## Возможности

- задачи на сегодня;
- все активные задачи;
- просроченные;
- выполнение, удаление и перенос;
- напоминания;
- клиенты и задачи клиентов;
- регулярные задачи;
- утренняя и вечерняя сводка;
- SQLite;
- хранение токена в `.env`.

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Скопируй `.env.example` в `.env`:

```bash
cp .env.example .env
```

Вставь токен:

```env
BOT_TOKEN=...
```

Запуск:

```bash
python3 bot.py
```

## Регулярная задача

Открой раздел `🔁 Регулярные`, затем отправь:

```text
/recurring
```

## Важно

Файл `data/bot.db` создаётся автоматически.
`.env` и база данных исключены из Git через `.gitignore`.
